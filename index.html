Send each document job to a worker that can do it, and keep proof of every handoff.

A coordinator routes fictional documents to OCR, validation, and results workers by capability, records a hash at each handoff, and recovers when a worker is missing or fails once. Leonel designed the operating pattern and its checks. It runs on one computer.

Leonel's role

Leonel designs and runs adaptable AI workflows across machines in Leonel's own practice, which this repository does not verify. Here he made the operating decisions, set the public proof scope and fictional fixtures, chose the failure cases, and wrote the acceptance checks. Coding agents helped implement the source, page, and tests.

  • Route by capability, not by machine. Workers are ocr-node or validation-node, so the coordinator role can move.
  • Waiting costs no attempt. A missing worker is not a failure; the job keeps its place.
  • Bounded retry. Two OCR attempts, then FAILED, so nothing loops forever.
  • Hash at every handoff. A changed delivered result is detected; the mutation check proves it.
  • Manual review stays required. Mock OCR proves nothing about accuracy, so the result says so.

What this does not prove

One computer. Fictional inputs. No remote node, TLS, production credential store, arbitrary upload, or private document. It does not establish general OCR accuracy, multi-computer reliability, production security, or operational outcomes.
