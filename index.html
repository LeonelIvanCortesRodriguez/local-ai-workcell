Operating boundary

What this run proves

Duplicate protection

Submitting identical bytes returns the existing job. A delivered result is never processed twice.

Bounded recovery

An unavailable OCR worker waits without consuming an attempt. A simulated failure uses one of two allowed attempts.

Honest evidence

The demo proves orchestration mechanics only. It does not measure OCR accuracy or represent a production deployment.
